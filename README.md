# Starlance

A 3D space rail shooter built with Three.js and Web Audio API.

## Features

- Fast-paced 3D rail-shooter action with retro arcade aesthetics
- Procedural audio sound effects using the Web Audio API
- Responsive controls supporting keyboard and touch interfaces
- Smooth camera panning, barrel roll dodges, and screen-clearing bombs
- Multi-stage encounters including enemy formations and a capital ship boss

## Controls

### Desktop / Keyboard
- **Move**: `W`, `A`, `S`, `D` or Arrow Keys
- **Fire**: Hold `Space`
- **Barrel Roll**: `Q` / `E` or double-tap Left/Right
- **Bomb**: `X`
- **Boost / Thruster**: `Shift`
- **Pause**: `P`

### Mobile / Touch
- **Steering**: Virtual stick on the left side of the screen
- **Fire**: Automatic while flying
- **Bomb**: Tap the BOMB button
- **Roll**: Tap the ROLL button

## Getting Started

Open `index.html` in any modern web browser or serve it with any static web server:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve
```
